1. Escribe una frase **«El usuario quiere…»** por cada necesidad. Debería haber **al menos 15**.
El usuario quiere **dar de alta** productos nuevos.
El usuario quiere **modificar** los datos de un producto.
El usuario quiere **eliminar** productos que ya no vende.
El usuario quiere **aumentar** el stock de un producto cuando recibe nueva mercancía.
El usuario quiere **reducir** el stock de un producto cuando realiza una venta.
El usuario quiere **evitar** que el stock de un producto sea negativo.
El usuario quiere **poner** un producto en oferta.
El usuario quiere **quitar** un producto de las ofertas.
El usuario quiere **consultar** la ficha de un producto concreto.
El usuario quiere **buscar** productos por su nombre.
El usuario quiere **filtrar** los productos por categoría.
El usuario quiere **ver** únicamente los productos que están en oferta.
El usuario quiere **ver** únicamente los productos agotados.
El usuario quiere **ordenar** los productos por nombre.
El usuario quiere **ordenar** los productos por precio.

2. Subraya (en **negrita**) el **verbo** de cada frase.

3. Agrupa las frases en las **cinco familias**: cambiar, buscar y filtrar, ordenar, resumir y validar.
Cambiar:
 El usuario quiere dar de alta productos nuevos.

 Buscar y filtrar:

 El usuario quiere filtrar los productos por categoría.
 El usuario quiere ver únicamente los productos que están en oferta.

 Ordenar:
 El usuario quiere ordenar los productos por nombre.
 El usuario quiere ordenar los productos por precio.
 El usuario quiere ordenar los productos por unidades disponibles.

4. Repasa cada familia y pregúntate si falta algo que la tienda vaya a necesitar.
